Rental Information

How renting works

  1. Register as a Customer (or login if you already have an account).
  2. Browse the available vehicles and choose one that suits you.
  3. Provide your pickup date, return date, and estimated distance (km).
  4. Choose whether you need a driver as well.
  5. Your booking is created as PENDING until an administrator confirms it.

Pricing formula

Total Cost = (Days × Daily Vehicle Rate)
   + (Distance in km × Rate per km)
   + (Days × Driver Daily Rate, only if a driver is requested)

All prices are shown in {{ currency_symbol }} (New Zealand Dollars).

Navigation, from any page

This web interface uses ordinary page navigation (buttons and links) instead of the CLI's keyboard shortcuts. To log out, use the Logout link in the top-right at any time.
